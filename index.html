Four buying guides

From saved link to shipping quote

01 / Source

Check LoloBuy product links

Open the original Weidian, Taobao or 1688 listing when a row supplies one. Match the item ID and seller name, then select the exact color and size to check availability. For a broken link, try searching the item ID or reverse-searching the original image. Confirm the seller and variant again before saving a replacement.

02 / Fit

LoloBuy size guide for shoes and clothing

For sneakers, compare foot length with the seller’s shoe size chart and ask for an insole measurement if you fall between sizes. For a hoodie or jersey, measure the chest width and body length of a piece you own laid flat. For pants, compare the laid-flat waist, rise and inseam. Check whether the size chart uses centimeters, inches or body measurements.

03 / Inspection

How to read LoloBuy QC photos

Check warehouse quality-control photos against the selected variant. Compare both heels and the size labels on a pair of shoes. For a jacket, look at seam alignment and the zipper. For a cap, check the brim and closure. For jewelry, request a clasp close-up and a ruler photo if you need to confirm chain length or bracelet circumference.

04 / Delivery

Build a LoloBuy shipping estimate

Record the item price, domestic delivery and any service fees separately. For US, UK or EU destinations, enter the actual country and postal code when the estimator requests them. Compare routes using the final packed dimensions and scale weight. Check how each route calculates volumetric weight, and confirm whether taxes or handling fees are included in the quote.

Frequently asked questions

What is a LoloBuy spreadsheet?

It is a product research list that groups listings by category. A row may include a source link, a variant, sizing notes or photos. Check the original listing before ordering.

How do I check whether a product link still works?

Open the original listing and confirm that the item ID, seller, color and size match the saved row. Check the selected variant for availability before relying on the link.

Can warehouse QC photos prove authenticity?

Warehouse QC photos can show visible condition, labels and measurements. Authenticity requires separate evidence, such as reliable provenance or qualified authentication.

How do I estimate shipping for my country?

Enter your destination and the packed parcel dimensions and weight in a current shipping estimator. Compare eligible routes and check whether the quote includes any destination charges.

Where do the category links go?

Each category opens the corresponding HipobuyFind catalog page. This page is an independent LoloBuy research guide.
